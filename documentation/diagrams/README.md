# Project Diagrams

This directory contains the following diagrams for the Quantum K-means project:

1. **DFD Level 0** (dfd_level0.png)
   - High-level system context diagram
   - Shows main system interactions

2. **DFD Level 1** (dfd_level1.png)
   - Detailed data flow between components
   - Shows major processing steps

3. **Activity Diagram** (activity_diagram.png)
   - Shows workflow of the system
   - Illustrates main processing activities

4. **Flowchart** (flowchart.png)
   - Detailed algorithm flow
   - Decision points and process flow

5. **Class Diagram** (class_diagram.png)
   - System architecture
   - Class relationships and methods

6. **ER Diagram** (er_diagram.png)
   - Data structure relationships
   - Entity attributes and connections

7. **Sequence Diagram** (sequence_diagram.png)
   - Component interactions
   - Message flow between objects

Usage:
1. Run generate_project_diagrams.py to create all diagrams
2. Diagrams will be generated in PNG format
3. All diagrams have white backgrounds for clarity
